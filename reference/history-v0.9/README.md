# history-v0.9 — retired fixtures of the v0.9 lineage

`sample_log_seed42.txt` is the v0.9 lineage's output for `--seed 42 --eras 20`
(LF line endings), generated by the v0.9 twin. It was the byte-identity golden
until v0.10 raised the Great Ridge floor from 4 to 5, which opened a new
lineage.

The live golden is now `../sample_log_seed42_v10.txt`, generated by
`../sim_v10.py`. Folders here are named for the **lineage** whose worlds they
describe, not the twin revision that produced them.
