# history-v0.5 — retired fixtures of the v0.5 lineage

`sample_log_seed42.txt` is the v0.5 lineage's output for `--seed 42 --eras 20`
(LF line endings). It was generated by the **v0.6 twin** — v0.6 added the
experimental fields dial (default off), which left the v0.5 lineage byte-identical,
so this one log is the canon fixture of both twin revisions.

It was the byte-identity golden until the v0.7 increment (Add Panel is the working
panel, and the v0.6.1 placement-score fix) opened a new lineage. The live golden is
now `../sample_log_seed42_v08.txt`, generated by `../sim_v08.py`.

Folders here are named for the **lineage** whose worlds they describe, not the twin
revision that produced them (see also `../history-v0.4/`).
