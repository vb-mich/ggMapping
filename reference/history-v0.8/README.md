# history-v0.8 — retired fixtures of the v0.8 lineage

`sample_log_seed42.txt` is the v0.8 lineage's output for `--seed 42 --eras 20`
(LF line endings), generated by the v0.8 twin. It was the byte-identity golden
until v0.9 made the community's deck the starting deck, which opened a new
lineage.

The live golden is now `../sample_log_seed42_v09.txt`, generated by
`../sim_v09.py`. Folders here are named for the **lineage** whose worlds they
describe, not the twin revision that produced them.
